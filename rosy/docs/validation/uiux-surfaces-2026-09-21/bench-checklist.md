# BENCH 회차 체크리스트 — 실물 증거 (D-153, 회차 8 예정)

HOST 회차(1–7)가 LOCAL 증거까지 채웠다. 이 문서는 실물 장치이 필요한 남은
G2/G3 분량의 **실행 프로토콜**이다. D-79: 이 회차의 판정은 아래 명령의 실행
시점 트리에서만 나온다. BENCH 캡처도 PIL 비공백 검증을 거친다(F-06 교훈 —
가능하면 상태 간 픽셀 diff로 교차).

## 준비 물품

| 물품 | 용도 |
|---|---|
| Rosy Pi 로봇(rosy-01, CORE 가동) | 콘솔·장비 런타임·얼굴 실물 |
| 전화 (로봇 AP 접속) | 콘솔 실물 뷰포트 390×844 계열 |
| 노트북 (로봇 AP 또는 LAN) | 콘솔 1280×720·얼굴 촬영 거리 기준 |
| 사이트 PC (가능 시, SiteHub 가동) | Fleet 1920×1080 실물 |
| 카메라/전화 카메라 | LCD 실물 사진(정면 1.5m + 0.5m) |

셀 명명: `<표면>_<상태>_<뷰포트>-bench.png` — 회차 폴더에 추가.

## 1. 운용자 콘솔 — 실물 단말

- [ ] 전화로 로봇 AP 접속 → `http://rosy-01.local:8080/dashboard`
- [ ] 노트북으로 동일 경로(1280×720 — `test_console_layout` 게이트 대응 실물)
- [ ] 상태 재현 가능 목록: fresh(정상 대기) / SAFE_STOP(E-Stop 후) / 401(잘못된
      토큰) / 불가역 확인(모드 변경 confirm — 스크린샷 대화상자는 네이티스트라
      **단말 사진**으로)
- [ ] 기록: 뷰포트 실측(px), 터치 타겟 체감(장갑 여부 — §7.1 "possibly gloved"),
      로딩 체감(최초 기동)
- 판정 입력: g3-checklist 콘솔 #4(위계 체감)·#7(질문 종합) — 실물에서

## 2. 장비 런타임 — 실물 Pi 값 (inspect 뷰)

- [ ] 실물 `/proc`·thermal → host 카드 정상값 셀(회차 5 대응 실물)
- [ ] RMW 정정 실측: 환경에 `RMW_IMPLEMENTATION=rmw_fastrtps_cpp`를 주고 CORE
      기동 → 대시보드가 FastDDS를 **보고만** 하는지(D-121) → CORE 재기동으로
      Cyclone 복귀 확인(D-122, 재부팅 아님) — 전후 캡처 2장
- [ ] 네트워크 카드 실물(SITE_STA SSID·IPv4·인터넷 도달)
- 판정 입력: 장비 #3(정상 그래프 무색)·#4(위계)·#7·#8(절차 순서)

## 3. Fleet console — 사이트 PC 실물

- [ ] 1920×1080 실물 뷰포트 — 가짜 응답 시험(`test_fleet_console_browser.py`
      방식)을 사이트 PC에서 재현하거나 실 SiteHub 구성
- [ ] 상태: 대형 활성·빈·gather 오류(최소 3종 — HOST와 동일 축의 실물 확인)
- 판정 입력: Fleet #3(한 행 예산 §7.3)·#4(위계)·#7

## 4. 로봇 얼굴 — LCD 실물

- [ ] `display/info` 퍼블리시로 4카드 상태 재현(정상·배터리 임계·E-STOP·빈
      페이로드) — CORE에서 JSON 발행
- [ ] 사진: 정면 1.5m(§7.4 가독 기준 — 0.5초에 읽히는가) + 0.5m 근접
- [ ] 만료-복귀 실측: `hold_s`(기본 15초) 후 감정 GIF 복귀 확인 — 명문화된
      모델의 실물 증거
- [ ] 백라이트 듀티(active/idle/standby) — PWR-003 계약
- 판정 입력: 얼굴 #3(1.5m 가독)·#7·F-07(영문 라벨·§7.4 긴장 — 소유자 결정)

## 5. 회차 종결 절차

1. 캡처 PIL 비공백 + 상태 간 diff(가능 분량)
2. g3-checklist 집계 표 최종화 — 위반 0 표면을 GO로(사람 서명 동반)
3. 회차 README Result 표 갱신, docs/logs.md 항목, harness generate·lint
4. GO도 "BENCH 분량 한정"임을 표기 — FIELD는 별도(D-91)

## 상한

이 회차의 증거는 BENCH까지다. FIELD(현장 운용 반복) 주장은 이 문서 범위
밖이다(D-153.3, D-91).
