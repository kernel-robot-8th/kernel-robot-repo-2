## 1. 목적과 합격의 의미

목표는 바닥의 직육면체 블록을 수거·운반·하역·적층하는 과정이 선택한 디바이스 구성에서 반복 실행 가능한지 확인하는 것이다. 아래는 향후 수행할 검증이며 이번 문서 작업으로 통과한 시험은 없다.

- SOURCE: 공식 문서·코드가 기능을 설명함.
- LOCAL: 선택 버전의 빌드·단위·통합 시험 통과.
- SIM: 해당 기구·환경 모델에서 시뮬레이션 통과.
- BENCH: 실제 카메라·암 또는 베이스 단독 시험 통과.
- FIELD: 실물 통합과 사용자 작업 시나리오 통과.

각 단계는 다음 단계의 증거를 대신하지 않는다. 이번 작업 결과는 SOURCE 수준의 조사와 시험 계획이다. 문서에 제안한 새로운 데이터 개념을 현재 API 계약으로 사용하지 않는다.

## 3. 단계별 수행 순서

### G0 — 모델 및 하드웨어 데이터 확보

제조사 확인과 실측으로 다음을 채운다.
- OMX 정확 모델과 기본판 포함 무게 범위, 자세별 허용 작업물 무게.
- 핑키 총중량, 상판 구조, 허용 적재하중 및 편심 하중 조건.
- 바퀴·캐스터 실제 접촉점, 베이스 무게중심, 장착 높이.
- 배터리 정격·최대 출력·보호회로, 12V 추가 공급 경로.

종료 조건: 계산·도면에 쓰는 값의 출처와 측정 방법을 기록했다. 필요한 값이 없으면 직접 탑재는 HOLD다. 모터 stall torque, URDF mass, 최대 도달거리로 값을 대체하지 않는다.

### G1 — 장착 공간·작업공간 검토

핑키+암+그리퍼+카메라+트레이를 같은 좌표계의 기구 모델로 배치한다. 기본판을 유지하는 안과 맞춤 고정부를 사용하는 안을 구분한다. 손가락 개방·접근·후퇴, 바닥·트레이·팔레트 상단 도달, 팔 수납, 배선 여유, LiDAR 시야를 확인한다.

종료 조건: 모든 목표 위치에 대해 허용 관절 범위 안에서 충돌 없이 수행할 후보 경로가 있다. 이 결과는 도달·충돌 후보 검증이며 기계적 강도나 전도 시험 통과가 아니다.

### G2 — 고정 암·카메라의 알려진 블록 시험

암을 적절한 고정 지지대에 설치하고, 알려진 단단한 블록 한 종류부터 진행한다. 고정 평면에서 촬영·전처리·좌표 추정·집기·이송·놓기·후퇴를 분리해서 확인한다. 바닥과 같은 높이 조건은 고정 시험대의 실제 기하에 맞춰 별도 구성한다.

종료 조건: 아래 위치·인식·동작·확인 오차 기준을 사전에 정하고 실제 결과로 충족한다. 모터 정지나 그리퍼 닫힘만으로 물체 성공을 기록하지 않는다.

### G3 — 핑키 운반·고정 작업대 연계

팔이 없는 핑키에 검증된 트레이와 짐을 실어 이동·정지·도착 후 재정렬을 확인한다. 고정 암 작업영역에 정지한 핑키에서 싣기·내리기를 시험한다. 통신 재연결 시 두 장치의 실제 상태를 다시 확인한다.

종료 조건: 짐 고정·주행·정지·재인식·하역을 반복할 수 있다. 이 단계는 임의 장소에서의 이동형 바닥 수거를 증명하지 않는다.

### G4 — 직접 탑재 조건부 시험

G0/G1에서 직접 탑재 검토가 성립할 때만 수행한다. 먼저 정지 상태의 제한된 암 자세·가벼운 실측 블록으로 시작하고, 검증된 수납 자세와 짐 상태에서 이동으로 확장한다. 전원 강하·온도·진동·기울기·짐 이동·센서 가림을 기록한다.

종료 조건: 선택한 장착 구조·블록·바닥·속도·자세 범위에서 실물 기준을 만족한다. 동시 주행·팔 동작과 더 큰 작업물은 별도 범위다. 기준을 만족하지 못하면 고정 작업대 배치를 유지하거나 더 적합한 베이스를 비교한다.

### G5 — 단층 배치에서 다층 적재로 확장

동일 크기 블록의 단층부터 여러 규격의 단층, 두 층, 더 높은 적층으로 나눈다. 각 단계에서 실제 지지·그리퍼 후퇴·하역 가능성을 확인한다. 지원이 부족한 배치와 원치 않는 가림은 후보에서 제외한다.

종료 조건: 실측 결과가 계획 위치·허용 오차와 맞고, 전체 적층 및 베이스 상태가 기준을 만족한다. 적재율 상승만으로 다음 단계에 진입하지 않는다.

## 4. 측정 항목과 합격 기준 설정

현재 숫자를 임의로 제품 보장값으로 고정하지 않는다. 시험 전 아래 빈 값을 정하고 변경 시 재시험 범위를 기록한다.

| 항목 | 측정 방법 | 합격 기준을 정하는 방법 |
|---|---|---|
| 물체 치수·질량 | 저울·치수 도구로 규격별 기록 | 모델별 허용 범위 및 오차 안 |
| 카메라 보정 | 재투영 오차 + 별도 실측 기준점 비교 | 픽셀 오차뿐 아니라 작업 공간의 mm 오차로 평가 |
| 집기 위치·방향 | 실제 기준점과 추정/실행 위치 비교 | 손가락 간격·접촉 면·자세 허용치에서 오차 예산 도출 |
| 배치 오차 | 놓은 후 위치·기울기 측정 | 적재 간격과 지지 여유보다 작아야 함 |
| 프레임 유효성 | 촬영~관측 사용 시각, 큐 길이·폐기율 | 유효 시간 초과 관측으로 새 동작을 시작하지 않음 |
| 지연 | 수집·전처리·추론·계획·제어별 p50/p95/p99와 최댓값 | 고정 해상도·부하별 예산을 사전 지정 |
| 주기 유지 | 암·베이스 제어 지연과 missed deadline | 선택 제어기 요구치와 자체 기준 모두 만족 |
| 전원·열 | 부하 전후 전압·전류·온도·재시작 여부 | 선택 부품 정격 내, 보호·리셋·과열 발생 없음 |
| 주행 안정성 | 가감속·정지·방향전환 시 짐 위치와 차체 상태 | 검증 범위 내 전도·들림·짐 이탈 없음 |
| 반복성 | 동일 조건 반복과 조건 변화 시험 분리 | 최초 성공률·재시도 후 성공률·실패 종류 각각 보고 |
| 적재 효율 | 점유 체적/정의한 유효 영역, 최고 적층 높이 | 실행·안정성 조건 통과 후 비교 |
| 작업 시간 | 한 물체 및 전체 작업 시간, 재시도 포함 | 사용자 목표 결정 후 통과선 지정 |

위치 오차 예산에는 카메라 보정, 대상 추정, 베이스 정렬, 암 실행, 기구 휨, 놓기 후 이동을 포함한다. 제조사 반복정밀도만으로 합산 오차를 대체하지 않는다. 작은 초기 반복 표본은 파일럿 결과로 표시하고 신뢰성 보장으로 표현하지 않는다.

| 주입/상황 | 기대 행동 제안 | 필요한 증거 |

실제 위험 상황의 시험 방법은 장비 상태와 제조사 절차에 맞춰 별도로 정한다. 문서만으로 비상정지 회로나 안전 기능의 적합성을 승인하지 않는다.

## 7. 산출물과 의사결정 기록

각 실험에는 구성 사진/도면, 소프트웨어 버전, 블록 규격, 원본 관측과 상태 로그, 실제 동작 영상, 성공·실패 판정 및 한계를 연결한다. 원본 이미지에 사람이나 현장 정보가 포함되면 필요한 범위만 보관한다.

현재: 문서·공개근거 재조사 완료를 목표로 작성했으며 G0~G5는 실행 전이다. 실제 장비 조건이 확보되면 모델 및 배치를 선택하고, 해당 범위의 구현 계획을 별도 문서로 만든다. 이번 문서화는 커밋·원격 전송·로봇 배포·실물 실행을 포함하지 않는다.
