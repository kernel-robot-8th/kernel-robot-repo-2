## 1. Bench Pi (G0~G5)

| 품목 | 규격 | 수량 | 용도 |
|---|---|---|---|
| Raspberry Pi 5 | 8GB 권장 | 1 | bench 본체 |
| microSD | 64GB 이상, A2 | 2 | 본番 + 예비 (굽기 실패 대비) |
| 전원 | Pi 5 정품 27W USB-C | 1 | 스로틀 방지 (실측 전제) |
| 유선 LAN | CAT5e + 공유기 포트 | 1식 | bench는 유선 (Wi-Fi 실측 변수 제거) |
| 방열 | 케이스 + 팬 또는 방열판 | 1식 | 스로틀은 실측을 망친다 |

## 2. 로봇 본체 (Pinky Pro 1대분)

| 품목 | 규격 | 비고 |
|---|---|---|
| 구동 | Dynamixel 2개 (ID 1·2), `/dev/ttyAMA4`, 1Mbps | G4 전제 |
| LiDAR | RPLidar C1 | G5 전제 |
| IMU | BNO055 | WIP 드라이버 — G5 전 아닐 수 있음, 없어도 G4까지는 간다 |
| 배터리 | 2S Li-ion 팩 + ADC | SAF-005 곡선 대상. 전류 센서 없음 (쿨롱 카운팅 불가) |
| 카메라 | OV5647 CSI | Task 5 실측 대상 |

## 4. 도크 1기분 (D0~D5)

| 품목 | 규격 | 비고 |
|---|---|---|
| ESP32 보드 | Wi-Fi STA·ADC·GPIO | 1 |
| 바닥 접점 한 쌍 + 로봇 측 접점 | DC, 이물질 단락 대비 절연 설계 | 맨접점 통전 금지는 펌웨어가 보증 |
| 전원 회로 | 2S 출력, 과전압 8.7V·과전류 3.0A 폴드백 | 임계값은 펌웨어 상수 |
| 전압·전류 센스 | 분압 1:4 + 션트 | `output_voltage_v`·`current_a` 공급원 |
| 태그 인쇄 | ArUco DICT_4X4_50 ID 7, 100mm, 무광 | photocopy 용지+합판이면 충분, 반사 금지 |
| 더미 로드 | 2S 부하 저항 | D2 통전 시험용 (로봇 접촉 전) |
