## 1. 결정 요약

**INFERENCE:** 직접 탑재가 불가능하다는 근거도, 가능하다는 근거도 아직 부족하다. 외곽판의 돌출은 간섭·강성 검토의 시작점이며 탑재 불가 판정 자체가 아니다. 핑키의 적재하중·지지 다각형·무게중심·상판 체결 구조가 필요하다.

**PROPOSAL:** 로지의 이동형 조작 목표는 유지한다. 직접 탑재 검토와 별개로 고정 암 + 핑키 운반 구성에서 인식·적재 계획·이송 계약을 검증할 수 있다. 후자는 이동형 로봇암 완성의 증거가 아니다.

UNKNOWN: 본체 질량, 정적·동적 적재하중, 상판 허용 모멘트, 휠 접점, 배터리 전압·용량, 외부 전원 인출 한도. 자료 미확보는 제조사 전체 문서에 존재하지 않는다는 뜻이 아니다.

## 3. 탑재를 판단하는 계산과 측정

### 질량과 전도

**PROPOSAL:** 전체 질량표를 만든다.

전체 질량 = 베이스 + 암 + 브래킷 + 적재함 + 카메라 + 전원 부품 + 케이블 + 모든 박스.

**INFERENCE:** 전도 경계는 상판 외곽이 아니라 실제 바퀴·캐스터 접점의 지지 영역이다. 정지 상태 무게중심 투영이 이 영역 내부에 있는 것은 첫 조건이며 급정지·팔 가속·경사 안정성을 보증하지 않는다. 각 팔 자세와 적재 조합에서 가장 가까운 전도 모서리까지의 거리와 복원 모멘트를 계산한다.

계산 예시: 100g 작업물이 암 기준 수평 0.4m에 있으면 작업물만의 중력 모멘트는 약 0.392N·m이다. 이는 전체 전도 모멘트가 아니다. 전도 모서리를 기준으로 각 부품 위치를 다시 합산해야 한다. OMX-F의 일반 도달 하중 250g을 임의로 이 위치에 적용하지 않는다.

**PROPOSAL:** 브래킷 체결부 하중과 처짐, 상판 소재, 나사 물림 깊이, 주행시 진동을 확인한다. 기본판 변경 가능성은 제조사 도면과 체결 요구조건으로 판단하며 임의 절단·천공을 전제하지 않는다.

### 바닥·적재함·팔레트의 도달성

**INFERENCE:** 도달 거리 하나로 바닥 집기가 보장되지 않는다. 장착 높이, 관절 제한, 손목 자세, 손가락 길이, 차체 간섭, 접근과 후퇴 궤적이 필요하다.

**PROPOSAL:** 바닥 집기 위치, 적재함 모든 슬롯, 팔레트 첫 층과 목표 최상층을 mm 좌표로 정의하고 아래 전체 궤적을 검사한다.

접근 → 그리퍼 개방 → 파지 → 수직 또는 지정 방향 이탈 → 운반 → 내려놓기 → 그리퍼 개방 → 후퇴.

목표 위치에만 IK가 있어도 중간 궤적이나 그리퍼 후퇴가 막히면 해당 슬롯은 사용하지 않는다. 암 장착부, LiDAR, 카메라, 케이블, 실린 박스 모두 충돌 모델에 포함한다. 바닥에 밀착된 박스는 손가락 하단이 바닥과 충돌할 수 있어 파지 높이·손가락 형상·작업물 간격을 별도 확인한다.

### 전원과 통신

**FACT:** 두 암 후보 모두 12V 표기가 있지만 핑키 전원에서 직접 공급할 수 있다는 뜻은 아니다.

**PROPOSAL:** 배터리 전압 범위, 보호회로, DC 변환기 연속·순간 전류, 접지, 퓨즈, 배선 정격을 먼저 확정한다. 집기·팔 상승·베이스 기동 조건별 전압 최저치와 피크 전류를 기록한다. CPU 재부팅, USB 단절, 모터 fault, 온도 상승을 같이 관찰한다. 통신 커넥터와 모터 전력 공급 경로를 구분한다.

**UNKNOWN:** 부하별 연속 운전 시간, 방열 여유, 핑키와 암 ROS 배포판·드라이버 조합의 실제 호환성. ROS 지원 표기만으로 Pi 동시 실행 성능이 검증되지 않는다.

## 4. 구성 대안

| 구성 | 목표 적합성 | 장점 | 남는 검증 | 판정 |
|---|---|---|---|---|
| 핑키 직접 탑재 | 목표와 일치 | 한 로봇이 바닥 수거·운반·하역 | 적재하중·전도·강성·전원·시야·도달성 | HOLD |
| 고정 OMX + 핑키 운반 | 지정 작업장 내 부분 검증 | 암 질량을 핑키에서 분리 | 도킹 오차, 운반 적재하중, 교환 작업영역 | 실험 설계 GO, 실기 미수행 |
| 더 큰 미정 베이스 + OMX | 목표와 일치 | 장착·적재·전원 여유를 요구조건으로 설계 가능 | 베이스 선정 전 모든 수치 검증 | 후보 요구조건 정리 GO |

이는 구매 추천이 아니다. 고정 암 구성에서는 임의 바닥 위치의 수거를 핑키 혼자 수행할 수 없으므로 사용자 목표를 완성했다고 보고하지 않는다.

## 5. 모델 선정 게이트

1. **작업물 게이트:** 실제 블록의 폭·깊이·높이·질량·마찰·파지 면을 측정한다. 처음부터 정격 최대 하중으로 시작하지 않는다.
2. **도달·자세 게이트:** 두 암의 정확한 URDF/CAD와 장착 후보별로 전체 궤적을 검사한다. 5자유도도 임의 6차원 자세가 모두 가능하다는 뜻은 아니다.
3. **운반 게이트:** 암·적재함·박스 합산 질량과 자세별 무게중심을 핑키 제조사 한도와 비교한다.
4. **전원 게이트:** 허용 공급 범위, 피크 부하, 안전한 종료 동작을 확인한다.
5. **실행 게이트:** 동일한 블록·슬롯·속도 조건에서 파지 및 배치 결과를 비교한다. 통과 근거가 생기기 전 모델을 확정하지 않는다.

## 6. 측정 가능한 수용 시험안

모두 **PROPOSAL**이며 수행 결과가 아니다. 물리 시험 시작 전 설계 담당자가 허용값을 기록해야 한다. TBD 값이 남은 상태를 합격으로 처리하지 않는다.

| 시험 | 기록 항목 | 통과 기준 |
|---|---|---|
| 실측·조립 확인 | 부품별 g, 체결부 mm, 접점 좌표, 전체 질량 | CAD/실물 차이 설명 및 제조사 허용 범위 충족 |
| 도달성 | 바닥/적재함/팔레트 슬롯별 접근·파지·후퇴 경로 | 사용할 모든 슬롯이 관절 제한·충돌·여유 기준 충족 |
| 정적 안정성 | 팔 자세·박스 조합별 모서리까지 거리, 체결 처짐 | 사전에 정한 안정 여유 충족; 바퀴 들림 없음 |
| 동적 안정성 | 승인 속도·가감속별 기울기·정지거리·적재물 이동 | 승인 범위 내 유지, 미끄러짐·들림 없음 |
| 전원 | 최저 V, 피크/평균 A, 온도, fault·재부팅 | 부품 정격과 제조사 조건 충족, 비의도 단절 없음 |
| 집기·배치 | 종류·위치별 제안 20회, 성공률·오차 mm/deg | 목표 성공률·배치 허용 오차를 시험 전 고정 |
| 운반·적층 | 한 층 후 두 층, 탈락·붕괴·위치 변화 | 정의한 반복 수 동안 탈락·붕괴 없음 |
| 중단·복구 | 작업 취소, 영상 유효기간 만료, 통신 단절 | 베이스 정지와 암 하중 유지/내려놓기 정책 수행, 자동 재개 없음 |

실제 전도나 최대하중까지 밀어붙이는 시험을 요구하지 않는다. 계산과 제조사 확인으로 승인된 범위 안에서 단계적으로 측정한다. 토크 해제 시 암이 처질 수 있으므로 “전원 끄기=안전 정지”로 정의하지 않는다.
