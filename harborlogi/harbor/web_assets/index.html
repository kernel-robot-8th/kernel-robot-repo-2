          Harbor

          반출대 내려놓기, 재취급 화물 복귀, 관련 팔 퇴피가 각각 대조돼야 합니다. 항목별 최신 원본 근거는 별도 확인이 필요합니다.

          화면 조회 시각은 원본 관측 시각이 아닙니다. 실행 승인과 정지는 ROSY Fleet에서 처리합니다.

          Harbor 사용 안내

          현재 업무와 다음 판단이 분명한 관제.

          Harbor에서 할 일

          조치가 필요한 업무를 찾고 계획·장부·실행 근거를 대조합니다. 현재 페이지는 조회 전용이며 업무 제안이나 현장 확인 제출은 제공하지 않습니다.

          ROSY에서 할 일

          원래 mission을 확인하고 운영자의 별도 세션에서 실행을 승인합니다. 로봇의 정지·복구도 Fleet과 장치 owner의 권한으로 처리합니다.

          이 화면을 읽는 기준

          데모는 합성 데이터입니다. 연결 실패·미확인·불일치와 빈 장부를 구분하고, Action 성공이나 receipt를 업무 완료로 바꾸지 않습니다. 실제 태블릿 공개와 운영 로그인·권한은 별도 준비가 필요합니다.
