화물의 업무 판단부터 실행 원본 대조까지, 각 화면에서 남길 결과를 확인하세요.

{% if can_read %}
  1. 01

    화물·요청 · 무엇을 언제 처리할까

    화물 ID와 점유 크기(1×1·2×1·3×1)를 등록하고 입고·반출 지시와 우선순위를 만듭니다. 크기 등록은 재고 배치와 구별됩니다.

    담당 · 업무 담당자 → 결과 · 화물·요청 revision
  2. 02

    재고·관측 · 어디에 있는가

    출처·시각·설치 기준을 확인하고, 검토할 원본을 선택해 요청으로 이동합니다. 과거 관측을 선택하면 그 선택을 다음 화면에 유지합니다.

    담당 · 관리자 등록 / 업무 담당자 검토 → 결과 · 선택한 관측 원본
  3. 03

    반출 관제 · 어떤 순서로 옮길까

    대상과 재취급 화물을 확인하고 재취급 → 반출 → 복귀 계획을 검토합니다. 미리보기는 예상 위치이며, 실제 위치 기록을 바꾸지 않습니다.

    담당 · 업무 담당자 → 결과 · 관측과 지시에 고정된 계획
  4. 04

    실행·대조 · 누구에게 인계됐는가

    Harbor에서 현재 단계의 제안을 제출합니다. ROSY Fleet의 다른 운영자가 원본과 자원을 검토해 별도로 승인합니다. 결과가 불명확하면 저장된 요청으로 원본을 대조합니다.

    담당 · Harbor 업무 담당자 → Fleet 독립 승인자 → ROSY 실행 소유자
  5. 05

    기록·검증 · 무엇으로 완료를 판단할까

    요청별 변경, 실제 배치, 재취급 복귀와 관련 팔 퇴피 근거를 확인합니다. Action 성공과 물리 receipt만으로 전체 업무를 완료하지 않습니다.

    담당 · 업무 담당자 → 결과 · 실행 시도와 연결된 완료 근거 대조
현재 운영 연결의 범위

다칸 계획은 검토할 수 있습니다. 실제 운영 인계에는 검증된 공간·장치 대응과 인증된 관측·업무 근거 연결이 필요합니다.
