# 컨테이너 직접 배치 작업 공간 구현 계획

**Goal:** 화물 선택 후 평면 목적 칸 클릭이나 기존 3D 핸들·좌표 입력으로 배치하고, 저장된 추천 이동을 불러와 이어서 수정한다.
**Architecture:** 기존 logical moveBox 검증과 연결 2D/3D를 재사용한다. 브라우저 draft의 이동 이력·되돌리기·다시 실행을 작은 모듈로 분리한다. 관측·불변 Plan·실행 인계는 기존 계약을 유지한다.
**Tech Stack:** Django templates, native ES modules, Three.js, Node assert, Edge/Playwright.
**Spec:** 설계26·ADR0014, 기존 가상 배치 계약. 사용자 요청에 따라 기존 웹과 모듈을 개선한다.

## 범위와 확인

- 편집 도구를 뷰어 밖 공통 상단으로 이동해 모바일 평면에서도 조작한다.
- 화물 선택→목적 칸 클릭으로 이동. 가능/불가와 이유, 변경 전후 주소 목록을 표시한다.
- 추천/선택 후보 결과는 원래 관측부터 저장된 이동 순서로 불러온다. 유효 경로가 아니면 전부 거절한다.
- undo/redo 뒤 새 이동은 redo 분기를 버린다. 재생은 현재 남은 유효 이력만 따른다.
- 새 저장/실행 API를 만들지 않는다. 가상 배치와 실제 지시를 혼동하지 않게 표시한다.
