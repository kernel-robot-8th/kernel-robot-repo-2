# 구역·칸 편집 구현 계획

기준: [설계 21](../../design/21-versioned-map-editor.md), [ADR 0009](../../adr/0009-versioned-flexible-maps.md).

1. 도메인: 가변 행·열·높이, 추가 보관 역할, 작업량 상한, 표시 메타데이터 검증. 기존 관측 호환과 실행 차단 회귀 검증.
2. 서버: 편집 DTO 변환, 원본 참조 필터링, 관리자/CSRF 검증 API, 새 불변 Condition 등록과 감사 이력. 원본 불변·새 관측 필요성 검증.
3. 화면: 구역 목록/속성/3D 미리보기, 칸 확대와 구역 추가·삭제, 검증 요약, 새 기준 등록. 설정/재고의 진입 경로와 미관측 맵 표시 통합.
4. 요구사항·용어 갱신. 단위·Django·JS 및 실제 브라우저 편집·등록·권한·기존 화면 회귀 검증.
5. 변경 검토·CE 판단·커밋 및 허가된 로컬 main 반영. 실제 로봇 수용과 구분하여 페이지와 증거 보고.

도메인/서비스와 편집 서버 모듈을 별도 작업자로 진행하고 화면·호출부 통합은 주 작업자가 담당한다. 공유 파일 소유권을 분리한다.

구현·검증 완료: [검증 기록](../../validation/2026-10-25-versioned-map-editor.md). 실물 교정/실행 수용은 이 기록의 완료 범위에 포함하지 않는다.
