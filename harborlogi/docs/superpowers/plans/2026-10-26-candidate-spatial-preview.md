# 저장된 추천 후보의 공간 비교

목표: 사용자가 저장된 비교 후보를 각각 2D·3D에서 단계별로 확인한다. 기존 ADR0014·설계26·브랜드 토큰·뷰어를 재사용한다. 비교 화면은 읽기 전용이며 계획 확정·실행 조작은 원래 계획 화면에서만 제공한다.

1. 후보2의 저장된 이동을 표시하고 원본 Plan·관측·감사·Command가 바뀌지 않는 회귀 시험을 먼저 작성해 RED를 확인한다.
2. 기존 공간 단계 생성기를 명시적 저장 이동 목록을 받는 함수로 재사용한다. 후보를 다시 탐색하거나 현재 관측으로 교체하지 않는다.
3. 권한이 적용된 GET 전용 후보 경로와 비교 전용 템플릿을 추가한다. 점수·원본·최신성 경고·후보 전환·단계·기존 연결 뷰어를 제공한다. 없는 후보·옛 자료는404, POST는405다.
4. Django 전체·필수 단위·실제 Edge의 원본/다른 후보·다칸 선택·모바일·GET 무변경을 검증한다.
5. 독립 검토·CI·GitHub 병합 후 로컬8060에 반영하고 Confluence에 실제 화면을 보존한다.

파일: `workspace.py`의 공간 단계 함수, `planning_pages.py`·`urls_product.py`의 읽기 경로, `recommendation_view.py`의 저장 후보 검증, 비교 템플릿과 추천 목록 링크, 해당 웹/브라우저 회귀 시험. 새 DB·외부 AI·ROSY API·자동 승인·실행 전이는 추가하지 않는다.
