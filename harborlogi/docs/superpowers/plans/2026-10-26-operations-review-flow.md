# 관제 검토 동선 개선

기존 ADR0011의 원본 보존·계획 설명 경계 안에서 진행한다.

1. 화물 경로의 단계 버튼은 직전 예상 배치를 즉시 기준으로 잡고 해당 이동만 느리게 보여준다. 가상 편집 중에는 혼합하지 않는다.3D가 없으면 같은 단계의 평면 원본을 보여준다.
2. 이전/현재 비교에 변경 항목만 보기와 명확한 빈 결과를 추가한다. 원본 Plan과 실행은 변경하지 않는다.
3. 관제에서 선택한 관측을 반출 목록·업무 새 검토에 전달한다. 저장된 Plan은 당시 원본을 유지하며 잘못된 관측 ID는404로 거절한다.
4. Django·실제 브라우저 단계/필터/출처 유지·기존3D 회귀를 검증하고 커밋/PR/CI/병합/로컬8060 반영과 기록을 마친다.

추가 사용자 지시: Harbor의 사용자 확정은 즉시 요청으로 연결한다. ADR0012로 현재 ARM 별도 승인 계약과 목표 UX를 구분하고 준비·제출을 한 POST로 잇는다. 불명 응답의 중복 전송은 회귀 시험으로 막는다. Fleet 정책 admission과 팔 자동 승인 계약 확장은 미구현 상태를 명시한다.
