# 지정된 칸을 기준으로 하는 3×3×3 야드

이 문서는 초기 3×3×3 예시의 설계 기록이다. 현재 제품은 [설계21](21-versioned-map-editor.md)과 [ADR0009](../adr/0009-versioned-flexible-maps.md)에 따라 가변 행·열·층과 추가 구역을 지원한다. 아래의 9칸·27위치 수치는 초기 설정에만 해당한다. 명시한 칸 ID·불변 기준·관측 누락 거절 원칙은 유지한다.

2026-10-25 사용자 정정: 현재 야드는 평면3행×3열, 높이3층이다. 전체27개 위치이며 한 층 전체에 화물 하나를 놓는 구조가 아니다.

설치 기준 Condition의 `yard_layout`에 `rows`, `columns`, `levels`, 그리고 칸별 `bay_id`·`row`·`column`을 고정한다. 현재 범위는3×3×3이며 모든9개 칸의 위치가 명시돼야 한다. ID의 철자나 관측 배열 순서로 위치를 추측하지 않는다. 별도 임시 칸·반출대는 맵 밖 보조 위치로 표시한다. 맵 안 임시 칸을 지정했다면 그 위치와 역할을 유지한다.

Bay는 한 평면 위치의 아래부터 쌓인 화물이다. 맵을 가진 원본에는 모든9개 칸의 관측이 있어야 하며 각 칸의 용량은3이다. 누락 칸을 빈칸으로 바꾸지 않고 입력을 거절한다. 같은 칸/좌표 중복·범위 밖·반출대/컨베이어와 맵 중첩도 거절한다. 기존 좌표 없는 기준/관측/계획은 유지하고 ‘좌표 미등록’ 목록으로 읽는다.

관측·예상 배치는 동일하게 층별3×3 평면으로 표시하고 1/2/3층을 선택한다. 빈 위치도 명시해27개 위치를 탐색할 수 있다. 행·열·층·원래 칸 ID·화물 ID를 함께 표시한다. 단계 변경 뒤에도 선택한 층을 유지하며 원본 관측을 쓰지 않는다. JS가 없으면 세 층 모두 읽을 수 있다. 재고 화면도 같은 맵을 쓴다. 이동 순서에는 출발/도착 칸과 층을 표시한다.

논리 맵 정본은 `config/yard-layout.json`이다. 칸 ID는 Y11~Y33, 위치 ID는 Y11-L1~Y33-L3이며 1행은 화면 위쪽·1열은 왼쪽·1층은 바닥층이다. 사용자가 기존 설정이 없으므로 작성하도록 요청한 기본 논리 주소다. 각 설치 기준은 정본을 `yard_layout`으로 복사해 불변 revision으로 보존한다. 맵이 바뀌어도 과거 계획의 좌표를 다시 해석하지 않는다. 같은 관측 출처의 새 원본은 설치 기준이 바뀌었어도 이전 계획을 무효화한다.

이 설정은 물리 좌표·팔 도달·보정·실행 허가를 만들지 않는다. 기존 planner는9개 Bay를 그대로 받으며, 지정된 임시 위치/허용 이동/팔 도달과 위 화물 선행 제거를 유지한다. `config/yard-grid.example.json`의 이동·도달 조건과 미리보기 화물 관측은 합성 시험용이다. 실제 설치의 허용 이동/도달 검증과 원본 producer를 대신하지 않는다.

구현 순서: (1) stdlib layout 검증과 시험 RED/GREEN, (2) 설치/관측 입력 검증과 고정된 지도 기반 stage/read model, (3) 층별 평면·선택·재고·합성 미리보기, (4) 전체 시험·네 폭/키보드/원본 보존·독립 검토·검증 기록·로컬 통합. 기존 Django/토큰/실행 권한을 확장하지 않는다.
