# ADR0011: 물량·재취급·재계획 차이를 근거별로 보인다

상태: 채택,2026-10-26 사용자 요청.

## 문제

자동 배치와 새 Plan 계산만으로 운영자가 무엇을 분리해 임시 장치하고 어디에 다시 적재하는지 알 수 없다. 기존 첫 화면은 조치 목록 중심이며 관측 재고·등록 지시·예상 재취급량을 한눈에 비교할 수 없다.3D 이동은 약1.1초이며 가상 편집 이력은 재생할 수 없다.

## 결정

1. 첫 화면에 선택한 관측의 화물 수·점유 위치/용량, 전체 등록 입고/반출 지시, 현재 계획의 예상 재취급 화물·이동 수, 원래 인계 상태를 구분해 표시한다. 관측 원본 시각·source·Condition과 freshness/provenance를 함께 보여준다. 등록 지시를 처리 완료/실제 물동량으로, 계획 READY를 실적/실행 허가로 바꾸지 않는다.
2. 실제 업무 완료 producer가 연결되지 않은 상태에서는 실제 완료량·처리율·시간당 물동량을 미집계로 둔다. TEU나 ton은 모형 한 개/격자 한 칸에서 추측하지 않는다. 물량은 화물 개체 수·위치 점유·등록 지시·계획상 이동의 단위를 명시한다. 과거 Plan을 합산하지 않고 요청별 현재 검토 Plan 또는 인계에 고정된 Plan을 구분한다.
3. 반출 작업 공간에서 목표 반출 화물과 사전 재취급 화물·복귀 화물을 분리해 표시한다. 각 화물의 관측 출발 → 임시 위치 → 반출/재적재 위치와 단계·역할을 보여준다. ‘분리’는 적재 묶음에서 화물 개체 전체를 옮기는 뜻이며 다칸 화물을 잘라 나누는 동작이 아니다.
4. 새 Plan에는 이전 Plan 대비 추가·제외·경로 변경·유지된 화물별 이동을 표시한다. 각 계획의 지시 revision·관측·Condition·크기 원본을 유지하여 비교한다. 제외는 새 제안에 포함되지 않는다는 뜻이며 기존 실행 취소가 아니다. HOLD는 부분 작업·예상 완료를 만들지 않는다.
5.3D 재생은 기본 약4.5초/이동으로 들어 올림·이동·내려놓기를 구분하고 화물 ID·출발/도착·진행 상태를 표시한다. 속도 선택·중지·단계 선택을 제공한다. 가상 편집도 원본에서 편집 결과까지의 유효 변경 이력을 로컬에서 재생한다. Reduced motion은 즉시 전환하고 문구/단계로 설명한다. 어떤 재생도 서버 관측·계획·명령을 변경하지 않는다.
6. 기존 API·계획·Command 권한은 바꾸지 않는다. 읽기 모델과 뷰어가 계산된 사실을 설명하며 새 물리 이동이나 실행 근거를 생성하지 않는다.

## 수용

다칸 화물 수/칸 점유 구분, 선택 관측 pin·오래됨·미관측, 과거 계획 중복 집계 방지, 인계 원본 우선, 실제 완료 미집계, 화물별 분리/반출/복귀와 이전 계획 차이를 검증한다. 실제 브라우저에서 느린 lift/transfer/lower의 중간 상태·속도·중지·가상 이력·원본 불변·권한·모바일·reduced motion을 확인한다. 실물/물동량 성능 수용과 구분한다.
