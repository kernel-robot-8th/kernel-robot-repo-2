# ADR 0009: 구역 편집은 불변 설치 기준의 새 버전을 만든다

상태: 채택 (2026-10-25)

구역을 늘리거나 칸 수를 바꾸어도 과거 관측·계획의 좌표 의미가 바뀌면 안 된다. 기존 Condition payload의 명시적 칸 정의를 가변 크기로 확장하고 보관 역할과 화면 배치 메타데이터를 추가한다. 편집은 새 Condition 생성으로 끝나며 원본을 수정하지 않는다.

추가 구역의 존재가 도달 가능성이나 임시 적치 권한을 부여하지 않는다. 구조가 달라진 참조는 상속에서 제거하고, 새 맵의 배치는 새 전체 관측으로만 확정한다. 서버 검증과 불변 모델을 기존 계층에서 재사용한다. 세부 DTO·화면·검증 규칙은 [상세설계](../design/21-versioned-map-editor.md)를 따른다.

독립적인 새 맵 DB 모델이나 전역 활성 맵 포인터는 현재 필요하지 않아 도입하지 않는다. 대가는 맵 버전 목록이 기존 설치 기준 목록에 포함된다는 점이다.
