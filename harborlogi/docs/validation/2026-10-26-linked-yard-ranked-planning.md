# 공간 보기 연계와 계산 추천 검증

2026-10-26. ADR0014·상세설계26. Harbor 계산·표시 검증이며 실물 실행을 뜻하지 않는다.

## 구현과 재현

2D·3D에서 개체/빈 위치를 양방향 선택하고 전체 점유 주소를 공유한다. 계획 단계·로컬 편집·복원도 같은 기준을 사용한다. 원본 SSR 평면은 무JS/렌더 실패의 읽기 경로로 보존한다. 미관측 맵의 위치를 빈칸이라고 표시하지 않는다.

공간 반출의 첫 성립 DFS를 완전한 유효 후보의 제한 비교로 바꿨다. 독립 전수 oracle, 전체 이동 replay, 나중에 도달한 더 나은 접두 경로의 재탐색, 동점의 결정성, 상태/후보 예산 전후 소진을 확인했다. 작은 고정 사례는34상태·142위치 검사·16완전 계획을 비교했고 `(0,1,1,2)`에서 `(0,0,0,3)`으로 복귀 위치 지표를 개선했다. 별도 실행에서0.00323초가 측정됐으나 제품 성능 보장이나 시험 임계값으로 쓰지 않는다.

입고는 길이3의 중간 화물을 통해 다른 열의 하부 우선 반출 화물이 연결되는 사례를 재현했다. 후보 열만 보던 점수 `(0,0,3)`이 누락을 드러냈고, 전체 지지 그래프 적용 뒤 `(1,0,3)`으로 정확히 집계됐다. 미정 순서는 unknown 항목에 별도로 포함한다.

## 검토와 한계

독립 검토의 두 지적을 수정했다: 모바일 보기 전환의 중간 위치 고정, 미관측 위치의 잘못된 빈칸 표현. 회귀로 해당 경로를 검증했다. 로컬 선택·가상 편집의 상호작용 POST0·원본 JSON 불변을 확인했다.

추천은 현재 모델이 허용한 작업군과 명시한 평가 기준 안의 계산이다. 탐색 한도 내 최선·완결 비교를 구분하며 실제 로봇 거리·시간·전체 항만의 전역 최적을 주장하지 않는다. 외부 AI provider는 추가하지 않았다. 기존 관측/설치/Command/승인/물리 근거 게이트를 보존한다.

운영 Fleet 선행 작업은 별도 소유 저장소의 기존 neutral ARM worktree에서 진행 중이며 이번 Harbor 검증의 성공으로 수용되지 않는다. CE: 해당 없음 — 원인·재발 방지는 코드·회귀·ADR에서 직접 확인할 수 있다. 운영 ARM·계정·복구의 기존 미해결 항목은 별도 기록에 남아 있다.
