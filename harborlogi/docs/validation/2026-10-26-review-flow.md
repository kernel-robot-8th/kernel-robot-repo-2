# 관제 검토 동선과 사용자 확정 제출

날짜: 2026-10-26. 기준: ADR0011·0012. 합성·격리 환경 검증이며 실물 수용이 아니다.

## 변경

관제의 선택 관측을 반출 목록 검색·업무 상세까지 전달한다. 저장된 계획은 당시 원본을 유지한다. 화물 경로에서 원하는 이동 단계만 재생하고 중지할 수 있다. 이전·현재 비교는 변경 항목만 표시할 수 있으며 변경이 없는 이유를 안내한다.

실행 가능한 계획의 사용자 확정 POST는 기존 준비·제출을 이어서 호출한다. 이미 제출됐거나 응답이 불명인 작업은 원래 Command로 이동한다. 중복 전송을 하지 않는다. 현행 ARM API의 독립 승인 요구는 남아 있으며, 별도 사람 클릭 없이 진행하는 목표 계약은 ADR0012에 명시했다.

## 확인

- Django 전체186개 통과. 선택 원본보다 최신 관측이 있어도 명시한 원본 유지, 잘못된 ID404, 비교·경로 읽기의 Plan 불변, 확정 POST의 실제 제출 시도 및 타임아웃 후 재POST 중복 방지를 확인했다.
- 도메인148개 수집,146개 통과·통합 설정이 필요한2개 skip. Node 점유·회전·애니메이션 모델 시험과 토큰 생성물 대조 통과.
- 실제 Edge 다칸 브라우저15개 검사 통과. 특정 화물 단계의 단독 애니메이션과 중지, 비교 필터·빈 상태, 가상 편집·재생·원본 보존, 네 화면 폭, reduced motion·무JS·WebGL 손실 복구를 확인했다. 브라우저 오류 없음.
- 전체 제품 브라우저7개 검사 통과. 로컬 근거: `runs/review-product-browser/run-22c5c98224574992a890a28ccbdd632f/report.json`.
- 로컬 근거: `runs/review-flow-browser/run-08656235560949bc861b1b1cd92bcd36/report.json`. 이 파일과 합성 DB·화면 자료는 커밋하지 않는다.

## 한계

실제 Fleet HTTP 계약 시험과 장치 실행은 이번 UI·앱 제출 변경에서 수행하지 않았다. 합성 미리보기는 Fleet에 연결하지 않는다. 다칸 실행 binding과 인증된 운영 관측·완료 producer 미수용 상태를 유지한다. Fleet 정책에 의한 ARM 자동 admission은 이번 변경에 구현되지 않았다.

CE: 해당 없음. 중복 제출 방지와 현행 계약의 한계는 코드·회귀 시험·ADR에 직접 기록했으며 추가 교훈 문서가 필요한 별도 환경 원인은 없었다.
