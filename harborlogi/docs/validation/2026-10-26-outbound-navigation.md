# 반출 화면 캡처와 아이콘 네비게이션

실제 Django 웹앱을 Edge에서 조작해 반출 목록, 업무 작업 공간, 관측3D, 반출 후 예상 배치, 복귀 평면도, 실행·완료 근거, 키보드 툴팁, 태블릿 목록, 모바일 메뉴의9개 화면을 촬영했다. 화물·관측은 합성이며 실제 로봇 운용이나 완료 근거로 간주하지 않는다.

PC 메뉴는76px 아이콘 레일을 기본으로 하고 이름을 펼칠 수 있다. 자체 SVG9종·기존 접근 이름·역할·현재 페이지를 유지했다. 포인터/포커스 툴팁의 hover 유지, Escape 닫기, 브라우저 선택 유지, 모바일/태블릿 이름 표시를 실제 브라우저로 검사했다. 모바일 열린 메뉴의 버튼 문구를 고쳐 열림 상태와 일치시켰다.

검증: Django156개 통과, 토큰 정본 일치, JS 구문 검사 통과. 기존 전체 제품 브라우저 회귀와 신규 메뉴 검사를1440/1280/768/390에서 수행했다. 새 캡처 도구도9장 저장 및 콘솔 예외 없음·가로 overflow 없음을 확인했다. 디자인 탐지기는 Django static 템플릿을 해석하지 못해 검사가 불완전했으며 실제 렌더 화면을 직접 검토했다.

로컬 증거: `runs/outbound-screens-2026-10-26/report.json`, `runs/icon-navigation-django.log`, `runs/icon-navigation-final/`의 실행별 report.json. 캡처는 `python tools/capture_outbound.py`로 기존 합성 로컬 preview에서 재현한다. 이 도구는 Fleet 호출이나 새 관측·계획 생성을 하지 않는다.

CE: 해당 없음 — 발견한 메뉴 문구 문제의 원인과 해결이 상태 갱신 코드와 브라우저 회귀 검사에 드러난다. 실물/Fleet 수용은 수행하지 않았다.
