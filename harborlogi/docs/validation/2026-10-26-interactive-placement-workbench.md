# 컨테이너 직접 배치·추천 경로 편집 검증

2026-10-26. 기준 main `24ccf2d272deb8c2b06c08889a3e90f2fa405c2a`. 설계26·ADR0014의 브라우저 가상 편집을 개선했다. 새 서버 저장/실행 API와 DB migration은 없다.

## 사용자 동작과 경계

편집 도구를 공통 상단에 두고, 화물을 선택한 뒤 평면 목적 칸 클릭/키보드 Enter로 이동한다. 전체 다칸 면적·충돌·지지가 성립하는 칸과 거절 이유를 구분한다. 선택은 유지되고 변경 전후의 전체 점유 주소를 표시한다. 기존3D 핸들·좌표 입력도 같은 검증과 이력을 사용한다.

되돌리기/다시 실행은 실제 저장된 가상 이동을 따른다. 되돌린 뒤 새 이동을 하면 redo 분기를 버린다. 저장된 계획/후보를 불러올 때는 관측부터 전체 이동을 한 단계씩 검증한다. 화물 집합·크기 revision·한 개체 이동·중간 지지가 틀리면 기존 이력을 바꾸지 않고 거절한다. 최종 위치만 복사해 중간 경로 검증을 건너뛰지 않는다.

모바일 평면 편집에서 canvas만 숨기고 지도 위에 화물 선택·결과 안내를 둔다. 좌표 입력과 오류도 아래에 유지한다. 화면의 가상 이력은 관측·불변 Plan·Command로 저장하지 않으며 실제 로봇 경로/물리 안정성이나 실적을 뜻하지 않는다.

## 근거

- Node RED로 도착 주소가 갱신되지 않는 기존 동작을 확인한 뒤 수정했다. 새로운 draft 모듈 시험은 이력 분기·다칸 주소·원본 불변·유효 추천 경로 불러오기·동시 다중 이동과 잘못된 크기 revision의 원자적 거절을 확인한다. map-editor/yard-model/yard-draft/yard-selection 네 도구가 통과했다. CI에도 새 이력 시험과 기존 selection 시험을 연결했다.
- Django 전체207 PASS. 필수 도메인 unittest156 실행 OK, opt-in 실제 Fleet 통합 클래스1개 skip. 이 skip은 실제 Fleet 통과가 아니다. migration 변경 없음, 토큰 생성 원본 일치.
- Edge 실제 WebGL 다칸 하네스는 exit0, report PASSED,22개 확인 항목이다. 마지막 합성 실행은 `runs/direct-placement-final/run-44e7e460955447b0a0ca41a5869309d2/report.json`.1440/1280/768/390px의 기존 후보·카메라·느린 재생·실제 핸들·fallback 회귀와 새 목적 칸 이동·지지/경계 거절·undo/redo 분기·후보2 불러오기·모바일 평면 조작을 확인했다. 비교/편집 중 POST0, Plan/Observation/Audit/Command 건수와 원본 JSON 불변이다.
- 독립 검토에서 성공한 키보드 이동 뒤 재생성된 목적 칸에 포커스를 찾지 못하는 P2를 발견했다. Enter 동작의 activeElement 검사로 RED를 재현한 뒤 성공 시 점유된 목적 칸에 포커스를 복구했다. 거절 시에는 기존 평면을 재생성하지 않아 목적 칸 포커스를 유지한다. 둘 다 브라우저 회귀로 확인했고 재검토의 잔여 P1/P2는 없다.
- PC·모바일 캡처를 직접 확인했다. 모바일은 평면을 좌표 입력보다 앞에 배치하고 선택/결과를 지도 가까이 둔다. 디자인 탐지기는 기존 CSS의 두 측면 테두리 경고를 냈다. 이번 변경의 새 색상·폰트·토큰은 없고 기존 브랜드 의미값을 사용한다.
- 격리 wheel build 성공. 새 yard-draft 모듈을 포함한 모델/선택/뷰어/CSS 다섯 자산의 wheel 바이트가 소스와 일치한다. 최초 no-build-isolation 시도는 로컬 venv에 setuptools가 없어 실패했고, 프로젝트 build-system을 사용하는 정상 격리 빌드로 검증했다.
